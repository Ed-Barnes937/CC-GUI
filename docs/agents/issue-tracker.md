# Issue tracker

Issues for this repo live in **GitHub Issues** on `Ed-Barnes937/CC-GUI`, via
the `gh` CLI.

- Specs and tickets from the engineering skills (`to-spec`, `to-tickets`,
  `triage`, `qa`) are created as GitHub issues.
- Ticket dependencies use native blocking links where available; otherwise a
  "Blocked by #N" line at the top of the issue body.
- PRs as a request surface: **off** — external PRs do not enter the triage
  queue.
